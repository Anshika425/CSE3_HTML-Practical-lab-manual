# CSE 3 – HTML Practical Lab Manual

This repository contains HTML practical experiments for the Web Designing subject.

## Experiments

| No. | Experiment | Topics Used |
|-----|------------|-------------|
| 1 | Course Curriculum Page | Text formatting, lists (ordered, unordered, description, nested, mixed), special characters |
| 2 | News Portal Page | Links, iframe (YouTube), video, audio |
| 3 | College Timetable | Table, rowspan, colspan, caption, nested table |
| 4 | Hotel Room Booking Form | Form, input fields, labels, select, textarea, buttons |
| 5 | Student Registration Form | Form attributes (method, action, placeholder, required), email validation |

## How to Run

1. Clone or download this repository.
2. Open the folder in VS Code.
3. Right-click any `.html` file and choose **Open with Live Server**.
   (or simply double-click the file to open it in a browser)
